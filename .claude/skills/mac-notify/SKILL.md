# mac-notify

## 概要

macOS の通知センターへデスクトップ通知を発火する。`osascript` の `display notification` をラップした `notify.sh` を呼び出すだけで完結する。

長時間かかるコマンド（デプロイ・E2E・ビルド）の完了をユーザに知らせる用途を主に想定する。

## 使うとき

- ユーザが `/mac-notify <title> <body>` を実行したとき
- ユーザが「終わったら通知して」「完了したら知らせて」と依頼したとき
- 長時間タスクの完了・失敗をターミナル外へ知らせたいとき

**使わないとき**: macOS 以外の環境。`notify.sh` が `uname` を検査して exit 1 で終わる。

## 実行手順

1. ユーザの入力から `title` と `body` を決める。
   - 引数を 2 つ受け取ったら、1 つ目を title、2 つ目を body にする。
   - 自由文だけを受け取ったら、要約を title、詳細を body にする。
   - どちらも決められないときはユーザに聞く。
2. スクリプトを実行する。

```bash
~/.claude/skills/mac-notify/notify.sh "<title>" "<body>"
```

3. exit code が 0 なら「通知を送った」とユーザに 1 行で報告する。

## クイックリファレンス

| 目的 | コマンド |
|---|---|
| 通知を送る（サウンド Ping） | `notify.sh "デプロイ完了" "erp-server-dev へのデプロイが成功した"` |
| 無音で送る | `notify.sh "ビルド完了" "エラーなし" none` |
| サウンドを変える | `notify.sh "E2E 失敗" "3 件のテストが落ちた" Basso` |

サウンド名は `/System/Library/Sounds/*.aiff` のファイル名（拡張子なし）を使う。例: `Ping` / `Glass` / `Hero` / `Submarine` / `Basso` / `Funk`。

## 引数の扱い

`title` と `body` は AppleScript の `argv` 経由でスクリプトが渡すため、引用符・バックスラッシュ・改行を含んでもエスケープが要らない。シェル側のクォート（`"..."`）だけを正しく閉じる。

```bash
# OK: 二重引用符を含む本文をそのまま渡せる
~/.claude/skills/mac-notify/notify.sh '警告' 'ファイル "a b.txt" が見つからない'
```

## よくある失敗

| 症状 | 原因と対処 |
|---|---|
| exit 0 なのに通知が出ない | システム設定 > 通知 で「スクリプトエディタ」または実行元ターミナルアプリの通知を許可する。おやすみモード（集中モード）も確認する |
| `使い方: notify.sh ...` が出て exit 2 | 引数が 2 個または 3 個でない。title と body を必ず渡す |
| `ERROR: macOS 以外では実行できません` | Darwin 以外の環境。このスキルは使えない |
| 通知が一瞬で消える | `display notification` の仕様。通知センターに残るので、消えたことを失敗と判定しない |

## 実装

`notify.sh` がすべての処理を持つ。Claude がインラインで `osascript` を組み立てず、必ずこのスクリプトを呼ぶ。
