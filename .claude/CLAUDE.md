# rule
* sed ではなく `gsed` を使ってください
* cat ではなく `gcat` を使ってください
* **pythonの利用は禁止です。** 大規模なファイルを編集する場合は、sed/awsコマンドか、Edit/Search/Grepツールを使え
* コードコメントは日本語で書いてください
* 調査やプラン検討
  * 関心事はある程度の塊に分割し、複数のエージェントを使って並行して調査・統合するようにしてください
* 調査しても答えが出ない時、 Web検索してください

# 日本語の記述

日本語を書くときは次のルールに従う。

* **である調で書く。ですます調にしない**
    * OK: 「この関数はエラーを返す」 / NG: 「この関数はエラーを返します」
* **結論・重要なことから先に書く**（重点先行）
    * OK: 「アップデート中は電源を切らないこと。システムを起動できなくなる」
    * NG: 「システムを正常に起動できなくなるので、アップデート中は電源を切らないこと」
* **一文を短くする**
    * 目安は50字前後。80字を超えたら分割する
* **一文一義で書く**（1文に1メッセージ）
    * NG: 「iPhoneはシンプルなデザインを特長とし、高い性能を持ち滑らかに動作する」
    * OK: 「iPhoneはシンプルなデザインを特長とする。高い性能を持ち、滑らかに動作する」
* **箇条書き・表を使い、並列性をそろえる**
    * 同じ階層の項目は品詞・粒度をそろえる
    * 順序に意味があるなら番号付きリスト、無いなら箇条書きにする
* **冗長表現を削る**
    * 「〜することができる」→「〜できる」
    * 「〜を行う」「〜を実施する」→「〜する」
* **肯定形で書き、二重否定を避ける**
    * NG: 「信頼できないアプリはインストールしないこと」
    * OK: 「信頼できるアプリだけをインストールすること」
